## About Me

Hey! I am **Shahriar Hossain**, a **Backend Software Engineer from Dhaka, Bangladesh**, and a **Full Stack / MERN developer** at heart. I have been building software since 2022: from co-founding **Lex.AI**, an AI legal assistant that won the **DIU Accelerator Cup 2023**, to shipping a commercial **IoT aquaculture platform** at **xFishery**, to building backends for web and mobile products at **SM Technology** today.

I build practical software with **Node.js**, **Express.js**, **TypeScript**, **React**, **Next.js**, **MongoDB**, **PostgreSQL**, **Redis**, **WebSockets**, **MQTT** and **Nginx**, turning product ideas into reliable, user-friendly applications that hold up in production.

### Currently Exploring

- Cloud automation and scalable backend design
- AI-assisted workflows, LLM integrations and developer productivity

### Interests

- Scalable SaaS systems and modern dashboards
- Real-time data integration, IoT monitoring, and automation
- Learning, debugging, and performance optimization
- How businesses and startups work, building teams and helping juniors grow
